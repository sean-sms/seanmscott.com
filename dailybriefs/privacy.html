Privacy policy

Last updated October 2, 2026

The Daily Briefs are personal tools used only by their owner. This page explains what it does with Google account data.

What it accesses

With the owner's permission, they use the YouTube Data API to read public video information (titles, lengths, view counts, upload times) from selected channels, and to create and update private playlists in the owner's YouTube account.

What it stores

The sign-in token and a short run log are stored only on the owner's own computer. Nothing is sent to any server operated by the developer, and no data is collected from anyone else.

What it shares

Nothing. No data is sold, shared, or used for advertising. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time from Google Account permissions. Deleting the tools' folder removes everything they stored.
